# 🎲 تختهٔ پولی ۵۰۰۰۰ — فصلِ یک‌روزهٔ بازار

بازی کاملِ **تختهٔ نرد ایرانی** با اقتصادِ میز: ورودی، شرطِ هر بازی، جابه‌جاییِ پول بینِ بازیکن‌ها،
مهلتِ یک‌روزه و جایزهٔ نقدیِ نفرات اول تا سوم. **نسخهٔ نمایشی است** — هیچ پول واقعی و هیچ درگاه
پرداختی وجود ندارد و همه‌چیز در حافظهٔ همین مرورگر نگه داشته می‌شود.

> **English.** A full Iranian backgammon (تخته نرد) game with a one-day cash-table tournament on top:
> a 50,000 Toman entry fee collected a week earlier, 20,000 T per game, live money moving between the
> 16 players, a 24-hour clock, and 10M / 5M / 1M Toman for the three players left with the most money.
> Every hand is dealt on a different hand-painted Persian board. Simulation only — no real money.

---

## اجرا

```bash
cd apps/takhte-pooli
node tools/serve.mjs            # → http://localhost:8137/
# یا:  python3 -m http.server 8137
```

باید از روی یک سرور باز شود (ماژول‌های ES روی `file://` با CORS می‌جنگند). هیچ وابستگی و هیچ build ندارد.

## چرخهٔ فصل

| مرحله | زمان | چه اتفاقی می‌افتد |
|---|---|---|
| پنجرهٔ ثبت‌نام | ۷ روز پیش از شروع | ورودی 50,000 تومان گرفته می‌شود و درِ میزها بسته می‌شود |
| روزِ مسابقه | ۲۴ ساعت | هر بازی 20,000 تومان؛ پول از بازنده به برنده می‌رود |
| پایان مهلت | لحظهٔ 24:00:00 | سه نفرِ بالای جدول 10,000,000 / 5,000,000 / 1,000,000 تومان به کیف پول می‌گیرند |

برای دیدنِ پایانِ روز در چند دقیقه، «سرعت زمان» در نوارِ پایین را روی 60× یا 600× بگذار، یا
«پرش به پایان مهلت» را بزن. در همین حال ۱۵ بازیکنِ دیگر هم واقعاً با هم بازی می‌کنند (موتورِ ربات‌ها
همان قوانین را اجرا می‌کند) و جدول زنده تکان می‌خورد.

## قوانینِ میز

- **تختهٔ چرخشی:** هر دست یک تختهٔ تازه — یزدی، اصفهانی، تبری، قاجاری، خراسانی، شیرازی، یلدا،
  فیروزه‌کوب. با هر تخته، پالتِ کل سالن (متغیرهای CSS) هم عوض می‌شود.
- **برد:** ساده ×1 · **مرس** (گمِین) ×2 · **تخته** ×3 — و در هر حالت ضربدرِ **کعب دبل**.
- **کعب دبل:** پیش از تاس ریختن؛ حریف یا می‌پذیرد یا با واگذاریِ شرط از بازی بیرون می‌رود. اگر
  تو دبل را پس بزنی، بازی را واگذار کرده‌ای.
- **پاداشِ رشتهٔ برد:** 3 برد پیاپی = 50,000 · 5 برد = 150,000 · 8 برد = 400,000 تومان؛
  به‌علاوهٔ 30,000 برای هر مرس و 100,000 برای هر «تختهٔ تمام‌عیار».
- **ساعت حرکت:** 20 ثانیه برای هر حرکت؛ تمام شود، بهترین حرکت خودکار بازی می‌شود تا روز کش نیاید.
- **تسطیح:** با پولِ میزِ کمتر از شرط، نشستن سرِ میزِ پولی ممکن نیست (حالت «دوستانه» همیشه باز است).
- **بازی نیمه‌تمام در پایان مهلت:** بی‌نتیجه است و شرط به صاحبش برمی‌گردد.
- **تساوی در جدول:** پولِ میز ← برد بیشتر ← تختهٔ بیشتر ← قرعهٔ تاس.

## کلیدهای میان‌بر

`Space` تاس / دست بعدی · `D` دبل · `B` بهترین حرکت · `U` بازگشت · `H` نظر استاد · `R` تسلیم ·
`M` صدا · `1…5` صحنه‌ها

## معماری

```
index.html            صحنه‌ها: میز بازی، جدول زنده، آمار، کیف پول، قوانین
css/app.css           رابطِ راست‌به‌چپ، شیشه‌ای، با متغیرهای رنگیِ تم
js/engine.js          قوانین تخته نرد: حرکت مجاز، وسط، خروج از خانه، مرس/تخته (توابع خالص)
js/ai.js              ارزیابی موقعیت + انتخاب دست + تصمیم دبل (۵ سطح، از تازه‌کار تا استاد)
js/board.js           رندر canvas: نقش‌های ایرانیِ ریاضی، مهره‌ها، تاس، کعب، انیمیشن پرواز
js/themes.js          ۸ تخته + پالتِ CSSِ هر کدام
js/tournament.js      اقتصاد: فصل، پول میز، شبیه‌سازی میزهای بقیه، ساعت مجازی، پرداخت جوایز
js/table.js           کنترلر میز: فازها، کلیک/حرکت، دبل، ساعت حرکت، تسویه
js/app.js             سیم‌کشیِ رابط، جدول زنده، آمار، کیف پول، مراسِم پایان روز
js/sound.js           افکت‌های WebAudio (چوب، تاس، سکه، فنفار) — بدون فایل صوتی
tools/serve.mjs       سرور ایستای بی‌وابستگی
tests/                ۲۲ آزمونِ قوانین + آمایِ دودِ کاملِ UI روی jsdom
```

هیچ تصویر و هیچ قلمِ بیرونی بارگیری نمی‌شود: تخته‌ها و نقش‌ها (گره‌چینی، کاشی هفت‌رنگ، کیلی‌باف،
شمسه، هرتی، آجرکوفی، شبِ ستاره، مس‌کوبی) روی canvas کشیده می‌شوند و قلم وزیرمتن
([OFL](assets/fonts/OFL.txt)) در `assets/fonts` همراه پروژه است.

## آزمون

```bash
npm test                        # قوانین + ساختار (۲۲ آزمون، بدون هیچ وابستگی)
npm i -D jsdom && npm run test:ui    # آمایِ دودِ UI
npm run test:all
```

آزمونِ UI یک دستِ کامل را با «کلیک روی تیِ منبع و مقصد» تا پایان پیش می‌برد، بررسی می‌کند که
جابه‌جاییِ پول مضربی از شرط باشد، همهٔ صحنه‌ها را رندر می‌کند، مهلت را تمام می‌کند و پرداختِ
جایزه را می‌سنجد.

## داده و حریم خصوصی

`localStorage` با کلید `takhte-pooli:v1` = فصل، جدول، کیف پول، آمار. هیچ درخواست شبکه‌ای به بیرون
نمی‌رود. دکمهٔ «پاک کردن همه‌چیز» در صحنهٔ کیف پول همه را از صفر شروع می‌کند.

⚖️ شرط‌بندی با پول واقعی در ایران غیرقانونی است. این پروژه برای تمرینِ بازی، تمرینِ احتمال و
هیجانِ رقابت ساخته شده؛ استفادهٔ مالی از آن با مسئولیت خودِ کاربر است.
